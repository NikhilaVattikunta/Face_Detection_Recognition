# Face Recognition & Attendance System

## Overview
This project is a real-time face recognition system built using OpenCV and Machine Learning.

## Features
- Face Detection using OpenCV DNN
- Face Recognition using KNN
- Unknown face detection
- Attendance logging system
- Streamlit UI

## Technologies Used
- Python
- OpenCV
- Scikit-learn
- Streamlit

## How to Run
1. Install dependencies
2. Run:
   streamlit run face_ui_pro.py
